# 🐠 AQUAVIBE — Reef & Deep Exotic Fish Store

> Премиальный интернет-магазин аквариумных рыб и рифовой биосферы с инновационным интерактивным сканером гидрохимической совместимости, живой базой данных и кислородной термобокс-доставкой.

---

## 🌊 Стек технологий

- **Frontend**: **React Native for Web** (`react-native-web`), React 18, Vite, Lucide Icons, Glassmorphic Bioluminescent UI
- **Backend**: **Python 3.11**, **FastAPI**, SQLAlchemy ORM, Pydantic v2, Uvicorn
- **Database**: **PostgreSQL 16** (с автоматическим сидированием каталога и отзывов при первом старте)
- **DevOps**: **Docker**, **Docker Compose**, **Nginx Reverse Proxy**

---

## 🚀 Быстрый запуск через Docker Compose

Все сервисы (PostgreSQL + FastAPI Backend + React Native Web Frontend) запускаются одной командой:

```bash
docker compose up --build
```

После старта будут доступны:
- 🌐 **Сайт магазина (Frontend)**: [http://localhost:3000](http://localhost:3000)
- 🔌 **API Swagger Docs (Backend)**: [http://localhost:8000/docs](http://localhost:8000/docs)
- 📊 **База данных PostgreSQL**: `localhost:5432` (пользователь: `aquavibe`, пароль: `aquavibe_secret`)

## ✨ Ключевые возможности проекта

### 1. 🧬 Интерактивный Биологический Сканер Совместимости
- Симулятор аквариума: добавьте в виртуальный аквариум до 6 видов рыб.
- Алгоритм гидробиолога в реальном времени анализирует:
  - 🌊 **Среду обитания**: предотвращает смертельную ошибку смешивания морских и пресноводных рыб.
  - 🌡️ **Температурный баланс**: вычисляет общий комфортный коридор градусов.
  - 🧪 **Кислотность (pH)**: проверяет совместимость биохимических параметров воды.
  - ⚔️ **Поведение и хищничество**: предупреждает о драках территориальных видов (петушки) или охоте хищников (Аравана, Крылатка) на мирных стайных неонов.
  - 💧 **Минимальный объем аквариума**: рассчитывает нужный литраж для комфортной жизни выбранной стаи.
- Возможность в один клик отправить всю гармоничную стаю в корзину!

### 2. 🎨 Не-ИИшный, сочный неоновый дизайн ("Bioluminescent Reef")
- Глубокая океаническая палитра (`#050814`) с биолюминесцентными акцентами неонового циана (`#00F0FF`), коралловой фуксии (`#FF2A85`), рифового изумруда (`#00FFA3`) и королевского пурпура (`#A855F7`).
- Анимированные всплывающие пузырьки и световые ореолы.
- Карточки с параметрами, бейджами статусов, индикаторами наличия и скидками.

### 3. 🔬 Досье на каждую рыбку (Modal)
- Фото высокого разрешения и ареал происхождения.
- Плашки гидрохимии: Температура, pH, Мин. объем, Рацион, Темперамент, Уровень сложности.
- Советы ихтиолога по адаптации и кормлению.
- Живые отзывы покупателей с возможностью поставить оценку и написать свой отзыв.

### 4. 🛒 Корзина и оформление доставки
- Индивидуальный расчет заказа.
- Включение сертифицированного термобокса с чистым медицинским кислородом (автономия тепла и дыхания до 48 часов).
- Выбор способа доставки и оформление заказа с получением уникального трек-номера (например, `AQV-74821`).

### 5. 📚 Памятка по капельной адаптации (Drip Acclimation)
- 4-шаговый иллюстрированный протокол ихтиолога для гарантированной 100% приживаемости рыбы без стресса.

## 🛠️ Локальный запуск без Docker (для разработки)

### Бэкенд:
```bash
cd backend
python -m venv venv
venv\Scripts\activate   # Windows (или source venv/bin/activate на Linux/macOS)
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### Фронтенд:
```bash
cd frontend
npm install
npm run dev
```
Фронтенд автоматически откроется на `http://localhost:3000` и будет проксировать `/api` запросы на бэкенд `http://localhost:8000`.
